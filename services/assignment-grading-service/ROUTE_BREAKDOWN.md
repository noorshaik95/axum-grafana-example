## How the System Works

### Auto-Discovery Process

1. Gateway queries service via gRPC reflection
2. Analyzes method names for patterns: `Create*`, `Get*`, `Update*`, `Delete*`, `List*`
3. Generates REST-style routes automatically
4. **Result**: 14 routes discovered

### Override Process

1. Gateway reads `gateway-config.yaml`
2. For each override:
   - If route was auto-discovered → replaces the path/method
   - If route was NOT discovered → adds new route
3. **Result**: 5 routes replaced, 7 routes added

### Final Result

- **21 total HTTP endpoints** serving 18 gRPC methods
- Some methods accessible via multiple paths (auto-discovered + override)
